I am a So Simple, Very Confident, Much Work, Such Cool Full Stack Developer

张飞达，6 年开发经验，现居上海，2020 年毕业于浙江理工大学 · 计算机科学与技术专业，英语六级。

如果让我用一句话定位自己，我会这样介绍：我是一名（偏前端）的高级全栈工程师，能独立完成前端、移动端、Node.js 后端到数据库并最终完成端到端交付；在 AI 和工程化理念的加持下，能够做到保质、保效地落地复杂业务。下面我用几次关键的跃迁讲一下我的成长经历。

起点：最早我其实是做 C# 方向，在校期间跟随导师做机器人巡检的项目。实习期基于 .NET + Vue 在苏州做政务服务系统。后来出于兴趣偏好转向前端，加入科锐数字科技，做 PC Web、H5、小程序三端，把前端工程化的底子打扎实了。

2022 年来到上海，加入 StoreHub 之后——一家做东南亚一体化 POS 的 SaaS 公司，服务上万商户。在这里我完成了更关键的三次跃迁。

第一次，从 Web 工程师转型为 React Native 工程师。精通掌握了 Redux-Saga、WebSocket 等异步处理方案，react-query、redux、redux toolkit、zustand、xstate 等状态管理，能独立负责 Android / iOS 应用的全流程交付，并开始下钻去改和实现部分 native module——真正掌握“大前端”技术栈，从“web H5 应用”到“跨端客户端应用”。

第二次，从中级晋升为高级工程师。这一跃更多是深度和责任的提升：我开始独立负责公司最复杂的业务模块——小票打印重构、局域网设备通信、从 0 到 1 搭建 KDS/NCS 应用。同时我能产出并汇报清晰的技术文档，能使用线上日志监控提前发现问题、在紧急故障时能够快速定位并修复。这个阶段的成果也很实在：我负责的核心模块相关线上工单减少了近 60%，单测覆盖率推到近 80%。

第三次，也是最近一年，从 React Native 工程师转型为全栈工程师。标志性项目是 SalonX——面向日本市场的美业 SaaS，我和一位同事 3 个月从 0 到 1 完成了 Web、App 和后端的整体交付，期间我们还承担了相当一部分 PO 和 Designer 的工作。这个项目对我有两层意义：一是我重新回顾并夯实了后端能力，真正成为全栈；二是我积累了大量用 AI 完成开发的一手经验，做了很多尝试，对 AI 的使用方式和能力边界有了非常清晰的认知。

所以走到今天，6 年经验，我可以把自己定位成一名能独立端到端落地的高级全栈工程师——能胜任复杂的业务场景，保质保效地完成交付。
